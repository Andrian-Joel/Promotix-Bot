Privacy Policy

Promotix Discord Bot

Last updated: August 3, 2026

1. Introduction

This Privacy Policy explains how Promotix (“the Bot”) collects, uses, and protects information when you use the service.

2. Information We Collect

The Bot collects and stores the following data only as necessary to provide its features:

  • Server (Guild) ID – to store per-server configuration
  • Rank Ladder Configuration – the ordered list of role IDs set by administrators
  • Log Channel ID – the channel designated for promotion/demotion logs
  • Command Usage – basic interaction data required for the Bot to function

The Bot does not collect or store message content, private messages, or unnecessary personal information.

3. How We Use Information

Collected data is used solely to:

  • Provide rank management and promotion features
  • Maintain server-specific settings (ladder and log channel)
  • Send optional action logs when configured

4. Data Storage

Configuration data is stored in a simple JSON file on the hosting server. No external databases or third-party analytics services are used by default.

5. Data Sharing

We do not sell, rent, or share your data with third parties. Data remains within the Bot’s hosting environment.

6. Data Retention

Server configuration is retained for as long as the Bot remains in the server. When the Bot is removed, associated configuration may be deleted during cleanup.

7. Your Rights

Server administrators can clear the rank ladder and change the log channel at any time using the Bot’s commands. You may also remove the Bot from your server to stop all data collection.

8. Security

We take reasonable measures to protect stored configuration data. However, no method of transmission or storage is 100% secure.

9. Children’s Privacy

The Bot is not intended for use by children under 13. We do not knowingly collect information from children.

10. Changes to This Policy

We may update this Privacy Policy from time to time. Continued use of the Bot after changes constitutes acceptance of the updated policy.

11. Contact

For privacy-related questions, contact the bot developer through the support channels provided with the Bot.
